# Gravity Hijack（グラビティ・ハイジャック）

スマートフォン縦画面・片手操作に特化した、WebRTC（PeerJS）による **1vs1 リアルタイム対戦型アクションゲーム**です。

GitHub Pages 等の静的ホスティングだけで動作する **単一HTMLファイル** で完結しています。

## 🎮 遊び方

1. ふたりとも同じURLを開く
2. ひとりが画面に表示された **4桁の数字（ID）** を相手に伝える
3. もうひとりは「相手のID」欄にそれを入力して「接続」
4. 両者「READY」を押すとカウントダウン後に対戦開始
5. 2分後により遠くまで到達したプレイヤーの勝ち

## 🕹 操作

- **スマートフォン**: 端末を左右に傾けて移動（ジャイロ）
- **PC**: `A` / `←` で左、`D` / `→` で右
- **「視界泥棒」解除**: 端末を激しく振る or `Space` を 5回連打

## ⚔️ ハッキング（妨害）

アイテムを取ると相手に妨害を送れます。

- **リバース・グラビティ**: 相手の画面を 5秒間 上下反転
- **エラスティック・ウォール**: 4秒間、左右の壁で強制バウンド
- **スモーク・チルト**: 視界を黒く覆う（端末を振るか Space連打で解除）

## 🚀 デプロイ

このリポジトリの `index.html` をそのまま GitHub Pages で公開するだけで動きます。
サーバーサイドは不要、外部ライブラリは CDN から読み込みます。
